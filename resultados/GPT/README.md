# Resultados documentais GPT

Esta pasta é exclusiva das revisões independentes produzidas por GPT e
executadas pelo Antigravity.

- Todo plano, relatório, evidência, rascunho e pacote GPT deve permanecer
  dentro de `resultados/GPT/`.
- `review/T0/` e os demais diretórios oficiais de fase pertencem ao
  fiscalizador principal Claude.
- O executor GPT/Antigravity pode consultar os documentos do fiscalizador, mas
  não pode criar, editar, mover ou apagar arquivos fora de `resultados/GPT/`.
- Nenhum conteúdo desta pasta equivale, por si só, ao veredito oficial de fase.
