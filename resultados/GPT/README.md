# Resultados das Revisões e Auditorias GPT / Antigravity

Esta pasta é reservada exclusivamente para o armazenamento dos planos de revisão, relatórios de auditoria independente, vereditos e artefatos de provas produzidos pelos modelos e executores GPT / Antigravity.

## Estrutura

- `PLANO_REVISAO_INDEPENDENTE_T0.md`: Plano diretor de auditoria independente para a Fase T0.
- `T0-auditoria-independente/`: Diretório contendo as corridas de auditoria por `RUN_ID` determinístico UTC.
